# 💼 ProConnect Job Tracker

A web-based job tracking application that helps users manage job applications, track progress, and stay organized during their job search.

## 🚀 Features
- User registration and login
- Add, update, and delete job applications
- Track application status (Pending, Interviewing, Declined)
- Store details like company, role, skills, and experience
- Simple and responsive UI

## 🛠️ Tech Stack
- HTML, CSS, JavaScript, React
- Node.js
- Express.js
- MongoDB
